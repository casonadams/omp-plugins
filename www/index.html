Getting Started

Manage plugins using the built-in oh-my-pi package manager.

1

Add the Marketplace

Register the official catalog in your local omp configuration.

omp plugin marketplace add casonadams/omp-plugins
2

Discover Extensions

Explore available extensions across all configured registries.

omp plugin discover
3

Install & Activate

Install plugins directly specifying the marketplace catalog scope. 

omp plugin install guard@casonadams-plugins
